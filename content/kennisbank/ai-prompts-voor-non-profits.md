> "AI is geen magie, het is een gereedschap. En zoals elk gereedschap werkt het beter als je weet hoe je het moet gebruiken."

Ik gebruik ChatGPT (en Claude) dagelijks. Niet voor revolutionaire AI-projecten, maar voor de saaie, tijdrovende taken die anders uren kosten.

In dit artikel deel ik 25 prompts die ik regelmatig gebruik. Je kunt ze direct kopiëren en aanpassen.

## Communicatie & teksten {#communicatie}

### Prompt 1: Nieuwsbrief schrijven

```
Schrijf een nieuwsbrief voor [ORGANISATIE] over [ONDERWERP].

Context:
- Doelgroep: [bijv. vrijwilligers, donateurs, deelnemers]
- Toon: [bijv. warm en informeel, professioneel]
- Lengte: [bijv. 300 woorden]
- Belangrijkste boodschap: [wat moet de lezer onthouden?]

Structuur:
- Pakkende opening
- Kern van het nieuws
- Call-to-action

Vermijd: jargon, te lange zinnen, passieve formuleringen
```

### Prompt 2: Social media posts (serie)

```
Schrijf 5 LinkedIn-posts voor [ORGANISATIE] over [THEMA].

Per post:
- 150-200 woorden
- Haak (eerste zin die aandacht trekt)
- Waardevolle inhoud
- Vraag of call-to-action
- 3-5 relevante hashtags

Toon: [bijv. professioneel maar toegankelijk]
Vermijd: te verkoopgericht, clichés, overmatig gebruik van emoji's
```

### Prompt 3: E-mail beantwoorden

```
Ik heb deze e-mail ontvangen:
[PLAK E-MAIL]

Schrijf een professioneel antwoord waarin ik:
- [punt 1]
- [punt 2]
- [eventuele actie aankondigt]

Toon: vriendelijk maar zakelijk
Lengte: kort en bondig
```

### Prompt 4: Persbericht schrijven

```
Schrijf een persbericht over [NIEUWSFEIT].

Informatie:
- Wie: [organisatie]
- Wat: [het nieuws]
- Wanneer: [datum]
- Waar: [locatie indien relevant]
- Waarom belangrijk: [context]

Structuur:
1. Pakkende kop
2. Onderkop met kernboodschap
3. Lead paragraph (wie, wat, wanneer, waar, waarom)
4. Citaat van [persoon met functie]
5. Achtergrondinformatie
6. Boilerplate over de organisatie
7. Contactgegevens

Stijl: journalistiek, feitelijk, geen marketingtaal
```

### Prompt 5: Uitnodiging evenement

```
Schrijf een uitnodiging voor [EVENEMENT].

Details:
- Wat: [beschrijving]
- Voor wie: [doelgroep]
- Wanneer: [datum en tijd]
- Waar: [locatie]
- Aanmelden: [hoe]

Toon: [enthousiast/formeel/informeel]
Lengte: max 200 woorden
Eindig met een duidelijke call-to-action
```

## Rapportages & documenten {#rapportages}

### Prompt 6: Gesprek samenvatten

```
Ik heb net een gesprek gehad. Hier zijn mijn aantekeningen:
[PLAK RUWE AANTEKENINGEN]

Maak hier een gestructureerd gespreksverslag van met:
- Datum en deelnemers
- Hoofdpunten besproken
- Besluiten genomen
- Actiepunten (wie doet wat wanneer)
- Eventuele vervolgafspraken
```

### Prompt 7: Jaarverslag tekst

```
Schrijf een tekst voor het jaarverslag over [ONDERDEEL].

Feiten en cijfers:
[PLAK DATA]

De tekst moet:
- Toegankelijk zijn voor leken
- Cijfers in context plaatsen
- Persoonlijk en warm zijn (niet droog)
- [X] woorden lang zijn

Structuur: inleiding - hoogtepunten - cijfers - vooruitblik
```

### Prompt 8: Evaluatierapport

```
Ik heb een project geëvalueerd. Hier zijn de ruwe data en observaties:
[PLAK INFORMATIE]

Schrijf een evaluatierapport met:
1. Samenvatting (max 200 woorden)
2. Doelstellingen vs. resultaten
3. Wat ging goed
4. Wat kan beter
5. Aanbevelingen voor vervolg

Toon: objectief, constructief
Lengte: [X] pagina's
```

### Prompt 9: Beleidsdocument

```
Schrijf een beleidsdocument over [ONDERWERP] voor [ORGANISATIE].

Het beleid moet:
- Doel en achtergrond beschrijven
- Concrete richtlijnen geven
- Rollen en verantwoordelijkheden benoemen
- Procedures beschrijven
- Praktisch en bruikbaar zijn

Doelgroep: [medewerkers/vrijwilligers/bestuur]
Lengte: max [X] pagina's
Toon: helder, niet juridisch, actief taalgebruik
```

### Prompt 10: Handleiding schrijven

```
Schrijf een handleiding voor [PROCES/SYSTEEM/TOOL].

De handleiding is voor: [doelgroep met niveau]

Structuur:
1. Introductie (wat en waarom)
2. Benodigdheden
3. Stap-voor-stap instructies
4. Veelgestelde vragen
5. Troubleshooting

Stijl: simpel taalgebruik, korte zinnen, veel koppen
Gebruik genummerde stappen en opsommingen
```

## Subsidies & fondsenwerving {#subsidies}

### Prompt 11: Subsidieaanvraag structureren

```
Ik wil een subsidie aanvragen voor [PROJECT].

Context:
- Organisatie: [beschrijving]
- Project: [wat wil je doen]
- Doelgroep: [wie help je]
- Budget: [bedrag]
- Fonds: [naam, als bekend]

Help me een structuur maken voor de aanvraag met:
- De kernvraag die ik moet beantwoorden
- Welke onderbouwing nodig is
- Hoe ik onze impact kan aantonen
- Mogelijke valkuilen
```

### Prompt 12: Begroting toelichting

```
Hier is mijn projectbegroting:
[PLAK BEGROTING]

Schrijf een toelichting op de begroting die:
- Elke kostenpost verantwoordt
- Aansluit bij het projectplan
- Uitlegt waarom bedragen realistisch zijn
- Eventuele risico's benoemt

Toon: zakelijk maar niet droog
```

### Prompt 13: Impact beschrijven

```
Ik wil de impact van [PROJECT] beschrijven voor een fondsaanvraag.

Wat we doen: [beschrijving]
Doelgroep: [wie]
Resultaten tot nu toe: [cijfers indien beschikbaar]

Schrijf een impact-sectie die:
- Concreet en meetbaar is
- Zowel output als outcome beschrijft
- Een logische keten laat zien (activiteit → resultaat → impact)
- Geloofwaardig is zonder overdrijving
```

### Prompt 14: Bedankbrief donateur

```
Schrijf een persoonlijke bedankbrief aan een donateur.

Naam: [naam]
Donatie: [bedrag/type]
Aanleiding: [indien bekend]
Project: [waar geld naartoe gaat]

De brief moet:
- Persoonlijk en warm zijn
- Concrete impact benoemen
- Niet te lang zijn (max 1 A4)
- Uitnodigen tot betrokkenheid (niet alleen geld)
```

### Prompt 15: Sponsorvoorstel

```
Schrijf een sponsorvoorstel voor [BEDRIJF] over [PROJECT/EVENEMENT].

Wij bieden:
- [zichtbaarheid/exposure]
- [netwerkmogelijkheden]
- [maatschappelijke impact]

Sponsor krijgt:
[opsomming tegenprestaties]

Investering: [bedrag/niveaus]

Maak het:
- Professioneel maar niet saai
- Gericht op wederzijds voordeel
- Met duidelijke call-to-action
```

## Vergaderingen & planning {#vergaderingen}

### Prompt 16: Agenda opstellen

```
Ik moet een agenda maken voor [TYPE VERGADERING].

Onderwerpen die aan bod moeten komen:
[OPSOMMING]

Beschikbare tijd: [X] minuten
Deelnemers: [rollen]

Maak een realistische agenda met:
- Tijdsindicatie per punt
- Doel per agendapunt (informeren/besluiten/bespreken)
- Eventuele voorbereiding voor deelnemers
```

### Prompt 17: Notulen verbeteren

```
Hier zijn mijn ruwe vergadernotities:
[PLAK NOTITIES]

Maak hier nette notulen van met:
- Datum, aanwezigen, afwezigen
- Per agendapunt: bespreking en besluit
- Actielijst met wie, wat, wanneer
- Datum volgende vergadering

Houd het bondig - alleen wat relevant is voor wie er niet bij was.
```

### Prompt 18: Projectplan

```
Help me een projectplan maken voor [PROJECT].

Doel: [wat willen we bereiken]
Deadline: [wanneer]
Budget: [indien bekend]
Team: [wie doet mee]

Het projectplan moet bevatten:
1. Projectdefinitie (doel, scope, resultaat)
2. Fasering met mijlpalen
3. Taakverdeling
4. Risico's en mitigatie
5. Budget (indien van toepassing)
6. Communicatieplan

Maak het praktisch en niet te uitgebreid.
```

### Prompt 19: Jaarcyclus planning

```
Help me een jaarcyclus plannen voor [FUNCTIE/AFDELING].

Vaste momenten:
- [bijv. jaarverslag in maart, subsidieronde in september]

Terugkerende activiteiten:
- [maandelijks, kwartaal, jaarlijks]

Maak een overzicht per maand met:
- Activiteiten
- Deadlines
- Verantwoordelijke (rol, niet naam)
- Voorbereidingstijd nodig
```

## Onderzoek & analyse {#onderzoek}

### Prompt 20: Data analyseren

```
Hier is data van [BRON]:
[PLAK DATA]

Analyseer deze data en geef:
1. De belangrijkste bevindingen (max 5)
2. Opvallende patronen of uitschieters
3. Vergelijking met vorige periode (indien beschikbaar)
4. Mogelijke verklaringen
5. Suggesties voor actie

Presenteer helder, niet te technisch.
```

### Prompt 21: Enquête ontwerpen

```
Ik wil een enquête maken over [ONDERWERP] voor [DOELGROEP].

Doel: [wat wil je weten]
Methode: [online/papier/telefonisch]
Tijd: [max X minuten invullen]

Help me met:
1. Introductietekst
2. [X] relevante vragen (mix van types)
3. Antwoordopties waar nodig
4. Afsluiting

Vermijd: dubbele vragen, sturende formuleringen, jargon
```

### Prompt 22: Sectorontwikkelingen samenvatten

```
Vat de belangrijkste ontwikkelingen samen in [SECTOR] over het afgelopen jaar.

Focus op:
- Beleidswijzigingen
- Trends in financiering
- Innovaties
- Uitdagingen

Maak het relevant voor een [TYPE ORGANISATIE] en beperk tot max 500 woorden.

Let op: gebruik alleen informatie tot je kenniscut-off en geef aan als je niet actueel bent.
```

### Prompt 23: Interview voorbereiden

```
Ik heb een interview met [PERSOON/FUNCTIE] over [ONDERWERP].

Context: [doel van het gesprek]
Tijd beschikbaar: [X minuten]

Help me met:
1. 5-7 goede open vragen
2. Mogelijke doorvraag per vraag
3. Onderwerpen om te vermijden (indien gevoelig)
4. Tips voor de gespreksvoering
```

### Prompt 24: Presentatie structuur

```
Ik moet een presentatie geven over [ONDERWERP] voor [PUBLIEK].

Tijd: [X minuten]
Doel: [informeren/overtuigen/inspireren]

Help me met:
1. Een sterke opening
2. Structuur (3-5 hoofdpunten)
3. Ondersteunende voorbeelden of data per punt
4. Sterke afsluit

Maak het praktisch - ik kan dit gebruiken om slides te maken.
```

### Prompt 25: Tekst versimpelen

```
Versimpel deze tekst voor [DOELGROEP]:

[PLAK TEKST]

Richtlijnen:
- Taalniveau: [bijv. B1, begrijpelijk voor iedereen]
- Vermijd: jargon, lange zinnen, passief taalgebruik
- Behoud: de kernboodschap en belangrijke details
- Lengte: [korter/gelijk/mag langer]
```

## Tips voor beter prompten {#tips}

### 1. Context is alles

**Slecht:** "Schrijf een nieuwsbrief."
**Goed:** "Schrijf een nieuwsbrief voor vrijwilligers van een welzijnsorganisatie, informele toon, 300 woorden, over onze nieuwe activiteiten dit najaar."

### 2. Geef voorbeelden

Als je een specifieke stijl wilt:
```
Schrijf in deze stijl:
[PLAK VOORBEELD]
```

### 3. Itereer

De eerste output is zelden perfect. Vraag om aanpassingen:
- "Maak het korter"
- "Minder formeel"
- "Voeg een voorbeeld toe"
- "Meer focus op [aspect]"

### 4. Gebruik structuur

Geef aan welke structuur je wilt:
- "Gebruik bullet points"
- "Structureer met koppen"
- "Maak een genummerde lijst"

### 5. Wees specifiek over toon

- Formeel / informeel
- Warm / zakelijk
- Enthousiast / neutraal
- Direct / voorzichtig

### Privacy-waarschuwing

**Let op:** Voer nooit persoonlijke gegevens van cliënten of gevoelige informatie in publieke AI-tools in. Anonimiseer altijd of gebruik enterprise-versies met verwerkersovereenkomst.

## Tot slot

Deze prompts zijn startpunten, geen eindpunten. Pas ze aan naar jouw situatie, organisatie en stijl.

Het doel is niet om AI al je werk te laten doen, maar om de saaie, repetitieve taken sneller af te handelen zodat je meer tijd hebt voor wat echt belangrijk is: het werk met mensen.

> "AI is geen vervanging voor denken. Het is een versnelling van het denkwerk dat je toch al moet doen."
