# Business Model Canvas voor sociale ondernemingen

**Leestijd: 9 minuten**

> "Jullie business model is niet compleet." Dat kreeg ik te horen van een investeerder. Niet omdat we geen geld konden verdienen, maar omdat we niet konden uitleggen hoe onze impact samenhing met ons verdienmodel.

Het klassieke Business Model Canvas van Osterwalder is briljant. Maar het mist iets cruciaals voor sociale ondernemingen: **de dubbele bottom line**.

In dit artikel laat ik zien hoe je het canvas aanpast voor impact-gedreven organisaties.

## Waarom het reguliere canvas niet werkt {#waarom-niet}

Het klassieke Business Model Canvas heeft 9 blokken die antwoord geven op:
- Wat bied je aan?
- Aan wie?
- Via welke kanalen?
- Wat kost het?
- Wat levert het op?

**Het probleem voor sociale ondernemingen:**

### 1. Wie is de klant?

Bij een regulier bedrijf is dit simpel: degene die betaalt.

Bij een sociale onderneming heb je vaak:
- **Begunstigden:** Degenen die je helpt (maar vaak niet betalen)
- **Klanten:** Degenen die betalen (maar niet altijd de directe begunstigden)

**Voorbeeld:** Een re-integratiebedrijf helpt werkzoekenden (begunstigden), maar wordt betaald door de gemeente (klant).

### 2. Wat is waarde?

In het reguliere canvas is waarde wat de klant bereid is te betalen.

Bij sociale ondernemingen heb je:
- **Economische waarde:** Wat levert het financieel op?
- **Sociale waarde:** Welke maatschappelijke verandering creëer je?

### 3. Wat is het doel?

Het reguliere canvas optimaliseert voor winst.

Sociale ondernemingen optimaliseren voor **impact**, met financiële duurzaamheid als randvoorwaarde.

## Het Impact Business Model Canvas {#impact-canvas}

Ik gebruik een aangepast canvas met 11 bouwstenen in plaats van 9:

```
+-------------------+-------------------+-------------------+
|                   |                   |                   |
|  IMPACT DOEL      |  BEGUNSTIGDEN     |  IMPACTMETING     |
|                   |                   |                   |
+-------------------+-------------------+-------------------+
|                   |                   |                   |
|  KEY PARTNERS     |  KEY ACTIVITIES   |  VALUE            |
|                   |                   |  PROPOSITION      |
|                   +-------------------+                   |
|                   |                   |                   |
|                   |  KEY RESOURCES    |                   |
|                   |                   |                   |
+-------------------+-------------------+-------------------+
|                   |                   |                   |
|  COST STRUCTURE   |  REVENUE STREAMS  |  KLANTEN          |
|                   |                   |  (betalend)       |
+-------------------+-------------------+-------------------+
```

De toegevoegde blokken zijn:
- **Impact Doel:** Welke maatschappelijke verandering nastreef je?
- **Begunstigden:** Wie helpt je (los van wie betaalt)?
- **Impactmeting:** Hoe weet je of het werkt?

## De 11 bouwstenen uitgelegd {#bouwstenen}

### 1. Impact Doel

**De vraag:** Welke maatschappelijke verandering wil je bereiken?

Dit is je Noordster. Alles wat je doet moet hieraan bijdragen.

**Goed:** "Ouderen 75+ in stedelijke gebieden voelen zich verbonden met hun buurt."
**Vaag:** "We willen eenzaamheid oplossen."

**Tip:** Maak het meetbaar. Als je niet kunt meten of je het bereikt, is het te vaag.

### 2. Begunstigden

**De vraag:** Wie profiteert van je werk?

Wees specifiek:
- Wie zijn ze? (demografie, situatie)
- Waar zijn ze? (geografisch)
- Wat is hun probleem?

**Let op:** Dit zijn niet altijd je betalende klanten.

### 3. Value Proposition (dubbel)

**De vraag:** Welke waarde creëer je - voor begunstigden én voor betalende klanten?

Je hebt twee waardeproposities:

**Voor begunstigden:**
- Welk probleem los je op?
- Wat krijgen ze van je?
- Waarom jij en niet een ander?

**Voor betalende klanten:**
- Wat krijgen zij terug voor hun geld?
- Welk probleem van hén los je op?
- Waarom zouden zij betalen?

**Voorbeeld:** Platform voor vrijwilligersmatching
- **Begunstigden (vrijwilligers):** "Vind betekenisvol werk dat bij je past"
- **Klanten (organisaties):** "Vind betrouwbare vrijwilligers zonder gedoe"

### 4. Betalende Klanten

**De vraag:** Wie betaalt voor je dienst/product?

Wees eerlijk over wie er betaalt:
- Eindgebruikers zelf?
- Organisaties?
- Overheden?
- Fondsen?
- Donateurs?

### 5. Kanalen

**De vraag:** Hoe bereik je je begunstigden én je betalende klanten?

Dit zijn vaak verschillende kanalen:
- Begunstigden: via zorgorganisaties, buurthuizen, huisartsen
- Klanten: via netwerken, accountmanagement, aanbestedingen

### 6. Relaties

**De vraag:** Welke relatie onderhoud je met beide groepen?

- **Met begunstigden:** Persoonlijk? Community? Zelfbediening?
- **Met klanten:** Accountmanagement? Geautomatiseerd? Partnership?

### 7. Key Activities

**De vraag:** Wat moet je doen om je waarde te leveren?

De kernactiviteiten die je impact mogelijk maken:
- Dienstverlening aan begunstigden
- Acquisitie van klanten
- Impactmeting en rapportage
- Productontwikkeling

### 8. Key Resources

**De vraag:** Wat heb je nodig om dit te doen?

- **Mensen:** Welke expertise?
- **Technologie:** Welke systemen?
- **Netwerk:** Welke relaties?
- **Kapitaal:** Hoeveel geld?

### 9. Key Partners

**De vraag:** Met wie werk je samen?

Sociale ondernemingen zijn zelden eilandjes:
- Doorverwijzers (wie stuurt begunstigden)
- Samenwerkingspartners (wie vult je aan)
- Financiers (wie investeert)
- Kennispartners (wie helpt je leren)

### 10. Cost Structure

**De vraag:** Wat kost het om je model te draaien?

- Vaste kosten (personeel, huisvesting)
- Variabele kosten (per begunstigde, per klant)
- Opstartkosten

### 11. Revenue Streams + Impactmeting

**De vraag:** Waar komt het geld vandaan én hoe meet je je impact?

**Revenue Streams:**
- Directe verkoop
- Subsidies
- Donaties
- Licenties
- Transactievergoedingen

**Impactmeting:**
- Welke indicatoren gebruik je?
- Hoe verzamel je data?
- Hoe rapporteer je?

## Praktijkvoorbeeld: DAAR Platform {#voorbeeld}

Laat me het canvas illustreren met een echt voorbeeld: DAAR, een platform voor vrijwilligersmanagement.

### Impact Doel
Vrijwilligers vinden betekenisvol werk, organisaties vinden betrouwbare hulp.

### Begunstigden
- Vrijwilligers die zinvol werk zoeken
- Organisaties met vrijwilligerstekort

### Value Proposition
- **Vrijwilligers:** "Vind vrijwilligerswerk dat bij je past, met de VrijwilligersCheck"
- **Organisaties:** "Vind geverifieerde vrijwilligers, beheer ze efficiënt"

### Betalende Klanten
- Welzijnsorganisaties (abonnement)
- Gemeenten (licentie)

### Kanalen
- Vrijwilligers: SEO, sociale media, lokale partners
- Organisaties: directe sales, netwerkevenementen, aanbestedingen

### Relaties
- Vrijwilligers: self-service platform, community
- Organisaties: accountmanagement, support

### Key Activities
- Platformontwikkeling
- Matching algoritme optimalisatie
- Klantsucces
- VrijwilligersCheck uitvoeren

### Key Resources
- Ontwikkelteam
- Database vrijwilligers
- Netwerk organisaties
- VrijwilligersCheck methodiek

### Key Partners
- Vrijwilligerscentrales
- Gemeenten
- UWV
- Welzijnskoepels

### Cost Structure
- Platformontwikkeling: 40%
- Sales & marketing: 25%
- Support & succes: 20%
- Overhead: 15%

### Revenue Streams
- Organisatie-abonnementen: 60%
- Gemeentelicenties: 30%
- Premium features: 10%

### Impactmeting
- Aantal succesvolle matches
- Retentie vrijwilligers
- Uren vrijwilligerswerk gefaciliteerd
- NPS beide groepen

## Workshop: je eigen canvas invullen {#workshop}

Hier is een stappenplan om je eigen Impact Canvas in te vullen:

### Voorbereiding (30 min)

1. Print het canvas op A3 of gebruik een digitaal bord
2. Verzamel post-its in 3 kleuren:
   - Geel: feiten (wat weet je zeker)
   - Groen: aannames (wat denk je)
   - Rood: vragen (wat moet je uitzoeken)

### Stap 1: Impact & Begunstigden (20 min)

Begin linksboven:
- Wat is je ultieme impact doel?
- Wie zijn je begunstigden?
- Welk probleem hebben zij?

### Stap 2: Dubbele Value Proposition (20 min)

Vul het midden in:
- Wat bied je begunstigden?
- Wat bied je betalende klanten?
- Waar zit de overlap?

### Stap 3: Klanten & Revenue (20 min)

Ga naar rechtsonder:
- Wie betaalt?
- Waarvoor betalen ze?
- Hoe ziet de inkomstenstroom eruit?

### Stap 4: Operations (20 min)

Vul linksonder in:
- Wat moet je doen?
- Wat heb je nodig?
- Wie helpt je?
- Wat kost het?

### Stap 5: Impactmeting (15 min)

Ga terug naar rechtsboven:
- Hoe meet je of je impact maakt?
- Welke indicatoren gebruik je?

### Stap 6: Review (15 min)

Bekijk het geheel:
- Hangt alles logisch samen?
- Waar zitten de rode post-its (vragen)?
- Wat moet je eerst valideren?

## Veelgestelde vragen

### Moet ik twee canvassen maken?

Nee, het Impact Canvas integreert beide dimensies. Je hebt één canvas met dubbele waardepropositie.

### Wat als mijn begunstigde ook mijn klant is?

Dan heb je een direct model en wordt het simpeler. Je hebt nog steeds het impact doel en de meting nodig.

### Hoe vaak moet ik mijn canvas updaten?

Bij een startup: elke maand bekijken, elke kwartaal updaten.
Bij een gevestigde organisatie: jaarlijks of bij grote veranderingen.

## Tot slot

Het Business Model Canvas is een krachtig hulpmiddel, maar het origineel is niet ontworpen voor sociale ondernemingen.

Door drie blokken toe te voegen - Impact Doel, Begunstigden en Impactmeting - maak je een canvas dat past bij de dubbele missie van sociaal ondernemerschap.

> "Een goed business model voor een sociale onderneming beantwoordt twee vragen: Hoe maak je impact? En hoe hou je het vol?"
